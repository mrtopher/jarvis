# Bruno - Git-native API Client

## Summary
> Open-source, **local-first API client** (REST, GraphQL, gRPC) that stores collections as plain-text files in your filesystem — a Postman/Insomnia alternative with no cloud, no login. Version collections in git alongside code. A dev-workflow tool for [[Dual Logic Platform]].

## Key Points
- **Git-native storage**: collections are folders + text files → native version control, no proprietary format.
- **Local-only**: explicitly no cloud sync/storage and no login requirement; data stays on-device.
- **Enterprise via git**: reuse existing git permissions for RBAC, audit logs, secret management.
- **Developer-first / anti-bloat**: extensible, intentionally lean vs. "bloated platform" competitors.
- **Collaboration through git workflows** rather than proprietary sync — no vendor lock-in.

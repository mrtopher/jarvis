# Keystone Headless CMS

## Summary
> Open-source Node.js **headless CMS**: describe a content schema in TypeScript/JS and Keystone auto-generates a GraphQL API + admin UI, database migrations (Prisma), and CRUD. "Superpowered Node.js Headless CMS for developers." Possible fit for content/admin surfaces in product builds like [[CATE]].

## Key Points
- **Schema-first**: define the model in code → auto-generated GraphQL backend + admin interface, no boilerplate.
- **100+ field types**: text through relational data, rich document editing, custom components.
- **Built-in access control**: session management, fine-grained authz, password auth out of the box.
- **Prisma-backed migrations** and TypeScript DX; "start fast, ship at speed."
- **Framework-agnostic**: GraphQL API pairs with any frontend; deploys to any infra (git-based workflows).

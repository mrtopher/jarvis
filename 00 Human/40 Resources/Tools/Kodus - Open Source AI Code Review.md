# Kodus - Open Source AI Code Review

## Summary
> Open-source **AI code-review** platform positioned as a CodeRabbit alternative: automates PR reviews across git platforms with your choice of LLM and no token markup. A candidate for the dev workflow on [[Dual Logic Platform]].

## Key Points
- **Model-agnostic**: Claude, GPT-4, Gemini, Llama, or any OpenAI-compatible endpoint — no lock-in.
- **Zero-markup pricing**: pay LLM providers directly; revenue is platform subscription, not token reselling.
- **Multi-platform**: GitHub, GitLab, Bitbucket, Azure DevOps — reads diffs, posts inline comments, respects existing review flow.
- **Custom rules in plain language**; can sync rules from Cursor/Copilot/Claude and validate against Jira/Linear/Notion requirements.
- **Privacy-first**: code never stored or used for training; encrypted in transit/at rest; self-hosted runners available.
- **Engineering metrics**: deployment frequency, cycle time, bug ratio, PR size; converts unimplemented suggestions into tracked tech-debt issues.

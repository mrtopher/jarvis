# Flue - The Open Agent Framework

## Summary
> Open-source **TypeScript** framework for building durable AI agents and workflows (powered by the Pi agent harness). Write-once, deploy-anywhere across any LLM, with session durability and automatic recovery as first-class concerns. A candidate building block / reference for [[Dual Logic Platform]] agent work.

## Key Points
- **Durable execution**: records every session in a durable stream and safely resumes interrupted work after a runtime/server outage — agents "can't die when the server goes down."
- **TypeScript-first**: define agents, tools, and skills in familiar Node.js/TS code.
- **Broad deployment targets**: Cloudflare, AWS, Docker, Railway; channel integrations for Slack, Discord, GitHub, Teams; datastores PostgreSQL, MongoDB, Redis.
- **Composable architecture**: configurable LLM, sandbox, reusable skills, typed tools — simple workflows through multi-agent systems.
- **Multi-LLM**: switch providers without changing agent behavior/infrastructure (no lock-in).

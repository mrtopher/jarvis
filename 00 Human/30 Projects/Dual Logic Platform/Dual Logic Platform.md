# Dual Logic Platform

## Goal
> Build a unified, AI-native platform to deliver [[Dual Logic]]'s client engagements (education cohorts, governance programs, technical solution work) from a single guided surface.

## Context
> Internal [[Dual Logic]] product (not a client engagement). Replaces ad-hoc delivery across Slack, Zoom, and scattered decks with one engagement-shaped surface: a guided journey, content and deliverables in one place, progress tracking, cohort interaction, a shared design system, and AI woven throughout, with the agency in the loop as the differentiator. Not a generic LMS. Code and docs live in the GitHub repo `Dual-Logic/platform` (mirrored read-only into this project's `repo-docs/`).

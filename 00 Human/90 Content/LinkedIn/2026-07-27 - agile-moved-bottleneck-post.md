# LinkedIn Post - Agile and the moved bottleneck

## Draft

Your engineers adopted AI. Your delivery did not get faster.

That gap is a process problem.

Agile was built when writing code was the slow part. Sprints, story points, the standup. All of it assumes code is expensive and hard to predict.

Gen-AI moved the bottleneck. Writing code is close to free now. The slow part is knowing what to build, verifying the output, and living with the code for years. None of that gets easier from a story-point estimate.

Keep what Agile got right: small batches, fast feedback, working software. The ceremonies need to point at the new bottleneck. Stop estimating how long a thing takes to build and start estimating how sure you are it is worth building. Give review real time on the calendar, because a senior engineer reading AI-written code is now the true limit on how fast you ship. When a validated change can go live in days, a two-week sprint is holding finished work hostage.

Ask your engineering leaders one question this week. Now that writing code is not the slow part, what is?
